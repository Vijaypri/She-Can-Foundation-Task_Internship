# She-Can-Foundation-Task_Internship
Frontend Development Internship Task

Create a simple single webpage for She Can Foundation.

Your webpage should include:
• NGO Name
• One Heading
• About Section
• One Image
• One Button
• Footer

You may use basic HTML and CSS.

🌱 We understand that many students applying are beginners who are still learning coding. As an NGO, we genuinely want to create opportunities where students can learn and grow without feeling pressured. That is why we have intentionally kept this task simple and beginner friendly.

✨ If you are an experienced coder, feel free to additionally add:
• Animations
• Responsive Design
• Dark Mode
• Interactive UI
• Creative Layouts
• JavaScript Features
